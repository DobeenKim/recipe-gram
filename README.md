<h1>Recipe-gram</h1>
<p>A recipe-sharing web application built with Next.js and Supabase.</p>

<h3>Tech Stack</h3>
<p>Frontend: Next.js (App Router), TypeScript, Tailwind CSS</p>
<p>Backend & Database: Supabase (Authentication, PostgreSQL Database)</p>

<h3>Key Features</h3>
<p>User Authentication: Sign up and login functionality using Supabase Auth</p>

<p>Recipe Management: Create, view, and edit recipes</p>
<p>Favorite Recipes: Ability for users to save and manage their favorite recipes for quick access and personal collection.</p>

<p>Responsive UI: Mobile and desktop layouts styled with Tailwind CSS</p>
